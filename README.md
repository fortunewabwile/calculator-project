# JavaScript Calculator

A simple calculator built in JavaScript that performs basic arithmetic operations and keeps a history of all calculations.

## Features

- Addition, subtraction, multiplication, division
- Division-by-zero protection
- Calculation history with operands, operator, and result

## Usage

Run in Node.js:

    node calculator.js

## Example

    add(5, 3);        // 8
    subtract(10, 4);  // 6
    multiply(6, 7);   // 42
    divide(20, 5);    // 4
    divide(5, 0);     // Error: cannot divide by zero.
